# My-app

My-app is a personal productivity dashboard built with React and Vite.

The project centralizes schedules, habits, goals, tasks, events, and personal workflows into one lightweight interface designed for organization and daily execution.

## Features

- Weekly schedule management
- Habit tracking
- Goal progress tracking
- Task management
- Event management
- Local browser storage persistence
- Mobile-first responsive design
- Dark UI optimized for focus
- Experimental Notion integration
- Browser notifications

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Notion MCP
- Anthropic API experiments
- Vercel
